Selective MoT: dense multi-future supervision, gated single-future readout

Same token sequence and video mask as Multimodal Joint (MM). Only the action rows change: per sample, a one-hot gate hides every future except the selected one, X. In SR-MoT (random), code name random_full_all, X is drawn uniformly per sample. In SR-MoT (router), code name router_full_all, the router samples X in training and takes the argmax at eval.

Your cascade has the same direction of dependency as ModAR (later modality conditioned on earlier ones), but ModAR conditions on a finished, clean earlier modality, while the cascade conditions on a noisy one being denoised at the same time. ModAR's training pass is a lower-triangular "clean prefix" pattern (C rows) plus queries that see only strictly earlier clean blocks and themselves (Q rows).

Equivalent short layout at inference

Futures never attend to each other, so dropping the hidden ones changes nothing for R0, Xf or A. SR-MoT with selected X equals the short layout [R0 | Xf | A]: max |afull − ashort| = 8e-6 in fp32, and 1,974 of 2,000 LIBERO episodes came out identical. Short is cheaper: 326 tokens against 718.

Mask code

# bool base, identical to MM
  allow = {"R0": {"R0"},
           "A":  {"R0", "A", "rgb", "depth", "flow"}}
  allow.update({n: {"R0", n} for n in streams})
  block = [[col in allow[row] for col in names]
           for row in names]      # repeat_interleave -> [S, S]
# per-sample gate on the action rows
  gate = one_hot(choice) -> 0 chosen / -1e4 others   # [B, 3]; -1e4 == blocked
  block_bias = cat([0, gate, 0])     # [B, R0 | rgb depth flow | A]
  col_bias   = repeat_interleave(block_bias, sizes)       # [B, S]
  mask = where(base, 0, -inf)[None]
       + is_action_row[None, :, None] * col_bias[:, None, :]  # [B, S, S]

Source: fastwam_joint_multimodal_select_new.py: _build_multistream_mot_attention_mask_base, _build_multistream_mot_attention_mask, _one_hot_gate.

Slot identity

The mask names the slots Rf, Df and Ff, but nothing in the tokens says which modality a slot holds: all three share RoPE positions and adaLN. Up to σ = 0.95 each slot reconstructs its own modality; at σ = 1, where inference starts, the starting noise decides. With seed 42 the Rf slot decodes depth, so X = R reads whatever the Rf slot produced. The stream embedding in router_full_all_streamemb_embed is the fix under test.
